# Chamod Arunodya — Portfolio

A responsive personal portfolio website built with React, Vite and CSS.

## Features
- Responsive layout for desktop and mobile
- About, skills, practice projects and contact sections
- React components and Lucide icons
- Clear labeling of sample/practice projects

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your real email address.
- Check that your education and skills are accurate.
- Keep the projects labeled as practice/demo work unless you have completed and verified them yourself.

## Tech stack
React · Vite · CSS · Lucide React
